En desarrollo

JFScript. Scripts de confianza.

Un pequeño lenguaje de scripting para apps hechas con JFLib. Los scripts se compilan a bytecode y se ejecutan en un sandbox con límites estrictos. Dan el mismo resultado, hasta el último bit, en cualquier máquina, y pueden pausarse en cualquier punto y continuar más tarde. Hoy JFScript ejecuta los servidores simulados de JFNetworker.

JFScript todavía está en desarrollo. El lenguaje, su biblioteca y la API de Rust pueden cambiar antes de que se publique por separado.

Familiar a primera vista.

Si has escrito JavaScript, Lua o Python, puedes leer JFScript. Tiene funciones y closures, listas y mapas, try y catch, y módulos mediante import. Los mapas conservan su orden, los enteros siguen siendo enteros y el texto cuenta caracteres, no bytes.

Cada script viene con una biblioteca estándar: texto, listas, mapas, bytes, matemáticas y JSON.

// las partes de una ruta de petición
let parts = "/users/42/posts".split("/")
  .filter(fn(p) { return len(p) > 0 })
let id = int.parse(parts[1]) ?? 0      // 42

// registros, con ordenación estable
let jobs = [{n: "b", prio: 2}, {n: "a", prio: 1}]
jobs.sort(fn(x, y) { return x.prio - y.prio })
print(jobs.map(fn(j) { return j.n }).join(", "))

// JSON conserva el orden de los mapas
let t = json.encode({id: 7, load: 0.5})
print("{:>4}|{:.2}".format(id, 0.5))    //   42|0.50

// los mismos bits en cualquier máquina
let load = 100 + 50 * math.sin(2 * math.pi * 3 / 24)
let shard = "user:42".hash() % 8

Qué lo hace diferente.

Determinista

Sin reloj, sin aleatoriedad y con coma flotante por software. Un script da los mismos bits en Windows, Linux, Android y en el navegador.

Aislado

Cada instrucción consume combustible. La memoria, la pila y la profundidad de llamadas tienen límites estrictos, así que un bucle infinito o una lista enorme simplemente terminan la ejecución.

Pausable

Ejecuta un script en tramos de cualquier tamaño y obtén el mismo resultado que de una sola vez. Se puede clonar una VM entera en mitad de una ejecución.

Solo tus nombres

Un script solo llega a las funciones que le da el host. Pasa al compilador tu lista de nombres y uno mal escrito será un error antes de que el script se ejecute, con una sugerencia.

Matemáticas exactas

Las funciones matemáticas son fdlibm sobre coma flotante por software: errores por debajo de un ulp, y exactas siempre que el resultado se pueda representar con exactitud.

Soporte de editor integrado

Autocompletado, información al pasar el cursor, firmas, ir a la definición, referencias, renombrado, plegado, un esquema y un formateador, también con código a medio escribir.

Integrado en unas pocas líneas de Rust.

Compila el código fuente, crea una VM con sus límites y ejecútala con tanto combustible por tramo como quieras. Tu host responde a las funciones que el script llama por su nombre. Los valores que viven más que una ejecución se fijan, y un valor obsoleto da un error en lugar de un cierre inesperado.

JFNetworker convierte el combustible en tiempo de CPU simulado: un script de servidor en un laboratorio consume tiempo como código real en una máquina real.

let prog = script::compile_named("server.jfs", src)?;
let mut vm = Vm::new(&prog, Limits::default());
loop {
    match vm.run(&mut host, 10_000) {   // combustible por tramo
        Status::Done(_) => break,
        Status::Yielded => continue,
        Status::Error(e) => { log(&e.to_string()); break }
    }
}
let req = vm.new_str("GET /")?;
vm.call("on_request", &[req])?;

Un ejecutor para la línea de comandos.

jfs ejecuta un script igual que python file.py ejecuta un archivo de Python. Comprueba scripts sin ejecutarlos, ejecuta las funciones test_* de los archivos de prueba, recorre el código paso a paso en un depurador de consola y ejecuta temporizadores con un reloj virtual y una semilla aleatoria fija.

Un script que solo usa la biblioteca estándar, print, log y temporizadores funciona igual en jfs y en JFNetworker.

jfs hello.jfs Anna Ben
jfs -e "print([3, 1, 2].sort())"
jfs --check hello.jfs
jfs --test tests/*.jfs
jfs --debug app.jfs
jfs --virtual-time --seed 7 sim.jfs

Módulos sin magia.

import es una función normal. Devuelve como mapa los nombres de nivel superior de otro archivo, sin los privados que empiezan por guion bajo. Cada archivo se ejecuta una vez por VM, y sus funciones siguen viendo sus propias variables globales.

// lib/util.jfs
let _calls = 0                 // privado
fn shout(s) { _calls += 1; return s.upper() + "!" }
fn calls() { return _calls }

// main.jfs
let util = import("lib/util.jfs")
print(util.shout("hello"), util.calls())   // HELLO! 1
