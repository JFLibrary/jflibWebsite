#![no_std]

Sin framework GUI por debajo. Todo de un mismo origen.

El renderizador, los widgets, los códecs de imagen, la red y la capa de plataforma viven en esta biblioteca, sobre core y alloc de Rust. No tienes que juntar un crate de ventanas, un bucle de eventos y un crate de interfaz, como hacen las apps de egui con eframe: una sola dependencia, jflib, es todo el stack. Escribe tu app también en no_std. Si necesita un crate que usa std, una feature activa std y se puede enlazar cualquier crate. Eso sí, no añadas un segundo bucle de ventanas ni ejecutes un runtime async en el hilo de la interfaz: JFLib ya tiene ambos.

Una app completa cabe en una pantalla.

// src/lib.rs
#![no_std]
#![deny(unsafe_code)]

extern crate alloc;
use jflib::{style, ui};
use ui::*;

const DESC: AppDesc = AppDesc {
    title: "Hello JFLIB",
    flags: AF_RESIZABLE,
    w: 480,
    h: 300,
    min_w: 320,
    min_h: 240,
    ..AppDesc::NONE
};

#[derive(Default)]
struct Counter {
    clicks: u32,
}

impl App for Counter {
    fn frame(&mut self, ui: &mut Ui) {
        ui.box_begin(0, BOX_V | pad(24), 12);
        ui.text(TS_TITLE, "Hello JFLIB!");
        ui.text(TS_BODY, &alloc::format!("Clicks: {}", self.clicks));
        if ui.accent_button(100, "Click me") & EV_ACT != 0 {
            self.clicks += 1;
        }
        if ui.button(101, "Reset") & EV_ACT != 0 {
            self.clicks = 0;
        }
        ui.box_end();
    }
}

ui::main!(ui::launch(&DESC, Counter::default(), &style::STYLE));
