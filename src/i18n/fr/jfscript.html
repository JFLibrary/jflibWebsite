En développement

JFScript. Des scripts fiables.

Un petit langage de script pour les applications créées avec JFLib. Les scripts sont compilés en bytecode et s’exécutent dans un bac à sable aux limites strictes. Ils donnent le même résultat, au bit près, sur chaque machine, et peuvent s’interrompre n’importe où pour reprendre plus tard. Aujourd’hui, JFScript fait tourner les serveurs simulés de JFNetworker.

JFScript est encore en développement. Le langage, sa bibliothèque et l’API Rust peuvent changer avant sa sortie en tant que projet indépendant.

Familier au premier coup d’œil.

Si vous avez déjà écrit du JavaScript, du Lua ou du Python, vous savez lire JFScript. Il a des fonctions et des closures, des listes et des maps, try et catch, et des modules via import. Les maps gardent leur ordre, les entiers restent des entiers, et le texte compte des caractères, pas des octets.

Une bibliothèque standard accompagne chaque script : texte, listes, maps, octets, maths et JSON.

// les parties d’un chemin de requête
let parts = "/users/42/posts".split("/")
  .filter(fn(p) { return len(p) > 0 })
let id = int.parse(parts[1]) ?? 0      // 42

// des enregistrements, triés de façon stable
let jobs = [{n: "b", prio: 2}, {n: "a", prio: 1}]
jobs.sort(fn(x, y) { return x.prio - y.prio })
print(jobs.map(fn(j) { return j.n }).join(", "))

// JSON garde l’ordre des maps
let t = json.encode({id: 7, load: 0.5})
print("{:>4}|{:.2}".format(id, 0.5))    //   42|0.50

// les mêmes bits sur chaque machine
let load = 100 + 50 * math.sin(2 * math.pi * 3 / 24)
let shard = "user:42".hash() % 8

Ce qui le distingue.

Déterministe

Pas d’horloge, pas d’aléatoire, et des nombres à virgule flottante calculés en logiciel. Un script donne les mêmes bits sous Windows, Linux, Android et dans le navigateur.

En bac à sable

Chaque instruction coûte du carburant. Mémoire, pile et profondeur d’appel ont des limites strictes : une boucle infinie ou une liste énorme met simplement fin à l’exécution.

Interruptible

Exécutez un script par tranches de n’importe quelle taille, et obtenez le même résultat qu’en une seule fois. Une VM entière peut être clonée en pleine exécution.

Uniquement vos noms

Un script n’atteint que les fonctions que l’hôte lui donne. Donnez au compilateur votre liste de noms, et un nom mal orthographié devient une erreur avant l’exécution du script, avec une suggestion.

Des maths exactes

Les fonctions mathématiques sont celles de fdlibm sur des flottants logiciels : erreurs inférieures à un ulp, et exactes partout où le résultat peut être représenté exactement.

Prise en charge des éditeurs intégrée

Complétion, infos au survol, signatures, aller à la définition, références, renommage, repliement, plan et formateur, même sur du code à moitié tapé.

Intégré en quelques lignes de Rust.

Compilez le source, créez une VM avec ses limites et exécutez-la avec autant de carburant que vous voulez par tranche. Votre hôte répond aux fonctions que le script appelle par leur nom. Les valeurs qui vivent plus longtemps qu’une exécution sont épinglées, et une valeur périmée provoque une erreur au lieu d’un plantage.

JFNetworker convertit le carburant en temps CPU simulé : dans un laboratoire, un script de serveur coûte du temps comme du vrai code sur une vraie machine.

let prog = script::compile_named("server.jfs", src)?;
let mut vm = Vm::new(&prog, Limits::default());
loop {
    match vm.run(&mut host, 10_000) {   // carburant par tranche
        Status::Done(_) => break,
        Status::Yielded => continue,
        Status::Error(e) => { log(&e.to_string()); break }
    }
}
let req = vm.new_str("GET /")?;
vm.call("on_request", &[req])?;

Un lanceur pour la ligne de commande.

jfs exécute un script comme python file.py exécute un fichier Python. Il vérifie des scripts sans les exécuter, lance les fonctions test_* des fichiers de test, parcourt le code pas à pas dans un débogueur en console et fait tourner les minuteries sur une horloge virtuelle, avec une graine aléatoire fixe.

Un script qui n’utilise que la bibliothèque standard, print, log et les minuteries tourne de la même façon dans jfs et dans JFNetworker.

jfs hello.jfs Anna Ben
jfs -e "print([3, 1, 2].sort())"
jfs --check hello.jfs
jfs --test tests/*.jfs
jfs --debug app.jfs
jfs --virtual-time --seed 7 sim.jfs

Des modules sans magie.

import est une simple fonction. Elle renvoie les noms de premier niveau d’un autre fichier sous forme de map, sans les noms privés qui commencent par un tiret bas. Chaque fichier s’exécute une fois par VM, et ses fonctions continuent de voir leurs propres variables globales.

// lib/util.jfs
let _calls = 0                 // privé
fn shout(s) { _calls += 1; return s.upper() + "!" }
fn calls() { return _calls }

// main.jfs
let util = import("lib/util.jfs")
print(util.shout("hello"), util.calls())   // HELLO! 1
