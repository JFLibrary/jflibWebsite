#![no_std]

Aucun framework GUI en dessous. Tout d’un seul tenant.

Le moteur de rendu, les widgets, les codecs d’image, le réseau et la couche plateforme vivent tous dans cette bibliothèque, au-dessus de core et alloc de Rust. Vous n’assemblez pas une crate de fenêtrage, une boucle d’événements et une crate d’interface, comme le font les applications egui avec eframe : une seule dépendance, jflib, forme toute la pile. Écrivez aussi votre application en no_std. Si elle a besoin d’une crate qui utilise std, une seule feature active std, et n’importe quelle crate peut être liée. Évitez seulement d’ajouter une deuxième boucle de fenêtre ou de faire tourner un runtime async sur le thread de l’interface : JFLib a déjà les deux.

Une application complète tient sur un écran.

// src/lib.rs
#![no_std]
#![deny(unsafe_code)]

extern crate alloc;
use jflib::{style, ui};
use ui::*;

const DESC: AppDesc = AppDesc {
    title: "Hello JFLIB",
    flags: AF_RESIZABLE,
    w: 480,
    h: 300,
    min_w: 320,
    min_h: 240,
    ..AppDesc::NONE
};

#[derive(Default)]
struct Counter {
    clicks: u32,
}

impl App for Counter {
    fn frame(&mut self, ui: &mut Ui) {
        ui.box_begin(0, BOX_V | pad(24), 12);
        ui.text(TS_TITLE, "Hello JFLIB!");
        ui.text(TS_BODY, &alloc::format!("Clicks: {}", self.clicks));
        if ui.accent_button(100, "Click me") & EV_ACT != 0 {
            self.clicks += 1;
        }
        if ui.button(101, "Reset") & EV_ACT != 0 {
            self.clicks = 0;
        }
        ui.box_end();
    }
}

ui::main!(ui::launch(&DESC, Counter::default(), &style::STYLE));
