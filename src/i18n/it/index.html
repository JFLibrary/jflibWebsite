core + alloc

#![no_std]

Nessun framework GUI sotto. Tutto dalle stesse mani.

Il renderer, i widget, i codec delle immagini, la rete e il livello di piattaforma vivono tutti in questa libreria, sopra core e alloc di Rust. Non devi mettere insieme un crate per le finestre, un event loop e un crate per l’interfaccia, come fanno le app egui con eframe: una sola dipendenza, jflib, è l’intero stack. Scrivi anche la tua app no_std. Se le serve un crate che usa std, basta una feature per attivare std, e puoi linkare qualsiasi crate. Solo, non aggiungere un secondo loop delle finestre e non far girare un runtime async sul thread della UI: JFLib ha già entrambi.

Un’app completa sta in una schermata.

// src/lib.rs
#![no_std]
#![deny(unsafe_code)]

extern crate alloc;
use jflib::{style, ui};
use ui::*;

const DESC: AppDesc = AppDesc {
    title: "Hello JFLIB",
    flags: AF_RESIZABLE,
    w: 480,
    h: 300,
    min_w: 320,
    min_h: 240,
    ..AppDesc::NONE
};

#[derive(Default)]
struct Counter {
    clicks: u32,
}

impl App for Counter {
    fn frame(&mut self, ui: &mut Ui) {
        ui.box_begin(0, BOX_V | pad(24), 12);
        ui.text(TS_TITLE, "Hello JFLIB!");
        ui.text(TS_BODY, &alloc::format!("Clicks: {}", self.clicks));
        if ui.accent_button(100, "Click me") & EV_ACT != 0 {
            self.clicks += 1;
        }
        if ui.button(101, "Reset") & EV_ACT != 0 {
            self.clicks = 0;
        }
        ui.box_end();
    }
}

ui::main!(ui::launch(&DESC, Counter::default(), &style::STYLE));
