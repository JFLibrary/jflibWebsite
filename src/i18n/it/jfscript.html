In sviluppo

JFScript. Script di cui fidarti.

Un piccolo linguaggio di scripting per le app create con JFLib. Gli script vengono compilati in bytecode e girano in una sandbox con limiti rigidi. Danno lo stesso risultato fino all’ultimo bit su ogni macchina, e possono fermarsi in qualsiasi punto e riprendere più tardi. Oggi JFScript fa girare i server simulati di JFNetworker.

JFScript è ancora in sviluppo. Il linguaggio, la sua libreria e l’API Rust possono cambiare prima che venga rilasciato come progetto a sé.

Familiare a prima vista.

Se hai scritto JavaScript, Lua o Python, sai leggere JFScript. Ha funzioni e closure, liste e mappe, try e catch, e moduli tramite import. Le mappe mantengono il loro ordine, gli interi restano interi e il testo conta caratteri, non byte.

Ogni script ha a disposizione una libreria standard: testo, liste, mappe, byte, matematica e JSON.

// le parti di un percorso di richiesta
let parts = "/users/42/posts".split("/")
  .filter(fn(p) { return len(p) > 0 })
let id = int.parse(parts[1]) ?? 0      // 42

// record, ordinati in modo stabile
let jobs = [{n: "b", prio: 2}, {n: "a", prio: 1}]
jobs.sort(fn(x, y) { return x.prio - y.prio })
print(jobs.map(fn(j) { return j.n }).join(", "))

// JSON mantiene l’ordine delle mappe
let t = json.encode({id: 7, load: 0.5})
print("{:>4}|{:.2}".format(id, 0.5))    //   42|0.50

// gli stessi bit su ogni macchina
let load = 100 + 50 * math.sin(2 * math.pi * 3 / 24)
let shard = "user:42".hash() % 8

Cosa lo rende diverso.

Deterministico

Niente orologio, niente casualità, e virgola mobile in software. Uno script dà gli stessi bit su Windows, Linux, Android e nel browser.

In sandbox

Ogni istruzione costa carburante (fuel). Memoria, stack e profondità delle chiamate hanno limiti rigidi, così un ciclo infinito o una lista enorme fanno semplicemente terminare l’esecuzione.

Interrompibile

Esegui uno script in porzioni di qualsiasi dimensione e ottieni lo stesso risultato che in un colpo solo. Un’intera VM si può clonare nel mezzo di un’esecuzione.

Solo i tuoi nomi

Uno script raggiunge solo le funzioni che l’host gli mette a disposizione. Passa al compilatore il tuo elenco di nomi, e un nome scritto male diventa un errore prima che lo script giri, con un suggerimento.

Matematica esatta

Le funzioni matematiche sono fdlibm su float software: errori sotto un ulp, ed esatte ovunque il risultato sia rappresentabile esattamente.

Supporto per gli editor integrato

Completamento, hover, firme, vai alla definizione, riferimenti, rinomina, folding, una struttura del codice e un formattatore, anche su codice scritto a metà.

Integrato in poche righe di Rust.

Compila il sorgente, crea una VM con i suoi limiti ed eseguila con tutto il carburante che vuoi per ogni porzione. Il tuo host risponde alle funzioni che lo script chiama per nome. I valori che vivono più a lungo di un’esecuzione vengono fissati, e un valore non più valido dà un errore invece di un crash.

JFNetworker trasforma il carburante in tempo di CPU simulato: uno script server in un laboratorio costa tempo come codice vero su una macchina vera.

let prog = script::compile_named("server.jfs", src)?;
let mut vm = Vm::new(&prog, Limits::default());
loop {
    match vm.run(&mut host, 10_000) {   // carburante per porzione
        Status::Done(_) => break,
        Status::Yielded => continue,
        Status::Error(e) => { log(&e.to_string()); break }
    }
}
let req = vm.new_str("GET /")?;
vm.call("on_request", &[req])?;

Un runner per la riga di comando.

jfs esegue uno script come python file.py esegue un file Python. Controlla gli script senza eseguirli, esegue le funzioni test_* dei file di test, percorre il codice passo passo in un debugger da console e fa girare i timer su un orologio virtuale con un seed casuale fisso.

Uno script che usa solo la libreria standard, print, log e i timer gira allo stesso modo in jfs e in JFNetworker.

jfs hello.jfs Anna Ben
jfs -e "print([3, 1, 2].sort())"
jfs --check hello.jfs
jfs --test tests/*.jfs
jfs --debug app.jfs
jfs --virtual-time --seed 7 sim.jfs

Moduli senza magia.

import è una semplice funzione. Restituisce come mappa i nomi di primo livello di un altro file, tralasciando quelli privati che iniziano con un trattino basso. Ogni file gira una volta per VM, e le sue funzioni continuano a vedere le proprie variabili globali.
