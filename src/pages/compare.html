How JFLib compares.

egui, gpui and Tauri are good choices for many Rust apps. Here is where JFLib takes another path, and where it is still behind. The facts about the others come from their own documentation and releases, as of November 2026.

Built in Partly, or from another crate Not available

Four different ideas.

JFLib

One library with everything an app needs, from the window to the installer, built on core and alloc. It draws every pixel itself, the same on every platform, and hands output, layers and images to the GPU.

egui

An immediate-mode UI library that turns widgets into triangle meshes. eframe adds windows on top of winit and paints the meshes with wgpu or OpenGL.

gpui

The framework behind the Zed editor, mixing immediate and retained mode on its own GPU renderer. Most widgets come from the separate gpui-component project.

Tauri

A web frontend in the system's webview, with a Rust backend behind it. The interface is HTML, CSS and JavaScript.

Where JFLib stands out.

Everything from one hand

Windows, widgets, text, images, network, packages and updates come from one library that is tested as a whole. No second window loop, no web stack.

The same pixels everywhere

Every widget is drawn by JFLib's own renderer, so an app looks the same on every platform and in every test. That is what makes pixel-exact tests possible.

Accessible by default

Screen readers on four platforms, high contrast, a separate text scale, full keyboard operation and right-to-left layouts, without extra crates.

Real desktop apps

Docking, ribbons, rich text, a code editor, data grids, file types, tray icons and jump lists are part of the library.

Tools in every app

The live inspector, test scripts, hot reload and an agent interface come with every build, and cost nothing when they are off.

Ready to ship

cargo jflib package builds installers and packages for Windows and Linux, with signing and signed updates.

Where others are ahead today.

An honest comparison names both sides.

Apple platforms

JFLib runs natively on Macs with Apple silicon and on the iPhone since November 2026, but not on Intel Macs, and without VoiceOver and Metal so far. egui, gpui and Tauri have been on macOS for longer, and Tauri on iOS too.

Maturity and community

Tauri has been stable since 2024, and egui is used in many projects. JFLib has just arrived on crates.io, with a smaller community so far.

The web ecosystem

With Tauri, every JavaScript library and every web developer's skills are available. JFLib apps are written in Rust only.
