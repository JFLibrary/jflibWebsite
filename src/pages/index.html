A complete GUI library in Rust.

Widgets, text, graphics, sound, networking and packaging in one no_std library with its own renderer. The same code runs on Windows, Linux, Android and in the browser.

--style winui,macos,kde,classic,jfoffice,backupcraft

Change the style. Keep the app.

Widgets are drawn by the selected style, so one interface can look like Windows, macOS, KDE or Office without touching your logic. Light and dark, accent colours and scaling change while the app runs. A small INI file lays your own colours, corners and spacing over any style.

--target win | linux | android | web

The same widgets everywhere.

Native windows, the browser host and the Android adapter share the same Rust widgets and the same renderer.

  • WindowsNative x86-64 app with desktop integration
  • LinuxNative x86-64 app, Wayland and X11, picked at startup
  • AndroidNative APK for Android 8 and later, Pocket Gallery so far
  • BrowserWebAssembly, tested on Chromium and Firefox
  • macOS, iOSThrough the browser for now, no native build yet
--target web

Whole apps in a browser tab.

Your app compiles to WebAssembly and keeps its widgets, its renderer and its screen reader support. The host picks a scalar, SIMD or threaded build based on what the browser can do.

#![no_std]

No GUI framework underneath.

The renderer, the widgets, the image codecs and the platform layer all live in this library, on top of Rust's core and alloc. A Python script calls rustc directly. Complex text shaping adds a small pinned Cargo project with HarfRust, linked statically.

Direct access to the graphics card.

For programs that need more than an interface: compute shaders, rendering with a depth test, indirect draws, timestamps and window swapchains, behind an explicit API in the style of Vulkan and WebGPU.

Images

Built-in codecs including PNG, JPEG, WebP, TIFF, AVIF and JPEG XL, an image viewer with zoom and pan, and SVG icons.

Sound

Output streams with a target latency over WASAPI, PipeWire, WebAudio and AAudio, mixed WAV and Ogg Vorbis sounds and the system's own sounds.

Desktop integration

Notifications, a tray icon, taskbar progress, jump lists, file types, global shortcuts, a screen colour picker and drag and drop with other programs.

Files and permissions

One file namespace with app://, config:// and mem://, assets inside the program, a PERMISSIONS manifest enforced at run time and the system's secret store.

Updates and packages

Signed updates with rollback, code signing, and packages from a Windows setup and .deb to AppImage, Flatpak, MSIX and RPM.

Network and security

HTTP, TLS 1.3, SMTP, an SSH client and DNS, modern cryptography, LZ4 and zstd, a journal database and encrypted repositories.

App framework

Logging, lifecycle hooks, typed settings with a generated settings page, saved window state and async tasks in the event loop.

A complete app fits on one screen.

#![no_std]
#![no_main]
#![deny(unsafe_code)]

extern crate alloc;
use ui::*;

const DESC: AppDesc = AppDesc {
    title: "Hello JFLIB",
    flags: AF_RESIZABLE,
    w: 480,
    h: 300,
    min_w: 320,
    min_h: 240,
    ..AppDesc::NONE
};

#[derive(Default)]
struct Counter {
    clicks: u32,
}

impl App for Counter {
    fn frame(&mut self, ui: &mut Ui) {
        ui.box_begin(0, BOX_V | pad(24), 12);
        ui.text(TS_TITLE, "Hello JFLIB!");
        ui.text(TS_BODY, &alloc::format!("Clicks: {}", self.clicks));
        if ui.accent_button(100, "Click me") & EV_ACT != 0 {
            self.clicks += 1;
        }
        if ui.button(101, "Reset") & EV_ACT != 0 {
            self.clicks = 0;
        }
        ui.box_end();
    }
}

ui::main!(ui::launch(&DESC, Counter::default(), &style::STYLE));
